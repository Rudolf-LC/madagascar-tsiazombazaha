# madagascar-tsiazombazaha
Dépôt GitHub des documents du stage de fin d'études réalisé par Ewen Le Coeur, ingénieur forestier AgroParisTech, pour Inter Aide, ONG de développement, à Manakara, Madagascar, du 15/04/2026 au 14/10/2026, portant sur l'étude sociale et écologique de la forêt tropicale humide de Tsiazombazaha.
